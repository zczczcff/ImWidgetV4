# ImWidgetV4 Library

This directory contains the reusable ImWidgetV4 library.

## Contents

- `include/imwidgetv4/`: public headers
- `src/`: library implementation
- `tests/`: library tests
- `samples/`: sample applications that consume the library

## Boundaries

This project should only contain framework-level runtime, widgets, rendering, platform integration, snapshot support, reflection, and reusable sample consumers.

Editor-specific document, panel, asset, and workflow code should live in `../ImWidgetV4Editor/`.
